# PROTO.DEV | Asistente de Precálculo

Proyecto de **Precálculo, sección B** — Universidad Mariano Gálvez de Guatemala.

- **Catedrático:** Ing. Reyes Baltazar Maza Guerra
- **Integrantes:** Jhónatan Emanuel Cúnay Quiñonez y Christian José Daniel Santos Cua

## Archivos
| Archivo | Para qué sirve |
|---|---|
| `index.html` | Estructura de la página |
| `style.css` | Diseño (colores, letras, cuadrícula) |
| `app.js` | Lógica: resolver, graficar, ejemplos y práctica |
| `logo_umg.webp` | Escudo de la UMG |

## Qué hace
- Resuelve ecuaciones, factoriza, deriva, integra, calcula límites en x → 0 y simplifica.
- Grafica funciones, orienta sobre dominio y rango, compone funciones y guía máximos/mínimos.
- 10 ejemplos listos y práctica con comprobación de respuesta.
- **Laboratorio Python:** código Python real que corre en el navegador (Pyodide).

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio y sube los 4 archivos a la raíz (no la carpeta, los archivos).
2. Entra a **Settings → Pages**.
3. En **Build and deployment** elige **Deploy from a branch**, rama `main`, carpeta `/(root)` y pulsa **Save**.
4. Espera 1 o 2 minutos y copia la URL pública.

> Necesita Internet: usa Nerdamer, Math.js, Plotly y Pyodide desde CDN. Verifica los resultados antes de entregar.
